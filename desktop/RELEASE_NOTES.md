## 下載安裝

| 系統 | 檔案 |
|---|---|
| Windows 10／11（64 位元） | `XiaokeEffects-Setup-版本.exe`（不需要系統管理員權限，可自選安裝資料夾） |
| Mac（Apple 晶片 M1～M4） | `XiaokeEffects-mac-AppleSilicon-版本.dmg` |
| Mac（Intel） | `XiaokeEffects-mac-Intel-版本.dmg` |
| 手機、平板、任何瀏覽器 | 線上版 https://achir1015.github.io/xiaoke-effects/（可「加入主畫面」） |

Mac 版沒有 Apple 簽章：第一次請在「應用程式」裡對 App 按右鍵 →「打開」。詳細說明在 .dmg 裡的「第一次開啟請看這裡.txt」。
已安裝的桌面版會自動提示新版本，按「立即更新」即可。
